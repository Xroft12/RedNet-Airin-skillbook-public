# Протокол сопровождения изменений manifest

Цель: любое изменение пакета навыков должно быть переносимым, проверяемым и обратимым.

## Перед изменением

1. Указать модуль, который меняется.
2. Указать причину изменения.
3. Проверить, что изменение не затрагивает live Hermes.
4. Проверить, что в diff нет секретов, приватных путей, сырого чата и session-файлов.

## Изменение

Для каждого навыка в manifest фиксировать:

- имя;
- путь;
- версия;
- слой;
- режимы;
- выключатель;
- публичность;
- зависимости;
- тесты;
- запреты.

## После изменения

1. Запустить dry-run installer.
2. Проверить JSON/YAML/Markdown.
3. Проверить ZIP-состав.
4. Обновить CHANGELOG.
5. Обновить `NEXT_START_HERE.md`.

## Откат

Если пакет ведет себя не так:

- не применять `-Apply`;
- оставить live Hermes без изменений;
- исправить manifest;
- пересобрать ZIP;
- повторить dry-run.
