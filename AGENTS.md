# AGENTS.md

Проектные правила для работы с репозиторием REDNET Airin Skillbook.

1. Рабочий язык проекта - русский. В пользовательских текстах, названиях разделов и документации не смешивать русский и английский без нужды. Английские идентификаторы допустимы в коде, путях, manifest и API-полях.
2. При разработке интерфейсов, витрин, карточек и визуальных материалов обязательно выполнять визуальную сверку результата. Красивое описание не заменяет проверку глазами.
3. Разработка должна доводиться до законченного состояния текущего этапа: если добавлен модуль, у него должны быть назначение, режимы, выключатель, проверка, граница данных и следующий шаг.
4. Если часть задачи не закрыта за один проход, нужно оставить явную точку продолжения: файл `NEXT_START_HERE.md`, чеклист или раздел "Открыто".
5. Live Hermes, Айрин, Алетию, VPN, Tailscale, роутеры, SSH и рабочие сессии не трогать из этого репозитория. Здесь лежит публичный Skillbook, установочные пакеты и безопасные прототипы.
6. Все навыки должны быть модульными: их можно установить, отключить, перенести, проверить и удалить без структурного вреда для агента.
7. Публичная версия не содержит сырой чат, дневники, PDF-капсулы, токены, ключи, OAuth/Telegram-сессии, приватные пути, рабочие базы и восстановимые настройки.
8. Каждый цикл разработки обязательно закрывается по `docs/cycle-close-protocol.md`: проверки, отчет, локальный архив, NAS-копия, commit и push в GitHub. Если закрытие не выполнено, следующий запуск начинается с восстановления закрытия цикла.
9. Реальные пути NAS, закрытые адреса и приватные параметры выгрузки не зашивать в публичные документы. Использовать параметр скрипта или переменную окружения.
10. Портал REDNET в этом репозитории - только read-only слой. В нем не должно быть live-команд, запуска Hermes Desktop, рестартов, публикации во ВК/Google или доступа к секретам.
11. ВК и Google для Айрин описываются как `draft-first` каналы: черновик, проверка приватности, ручное подтверждение, затем публикация.
12. Марсель отражается как тихий изолированный помощник. Не переносить ему личную память Айрин/Алетии, дневники, raw thread, OAuth/Telegram-сессии или ключи.
13. Docker-монитор в портале показывает только read-only статусы. Runtime-файлы в `portal/runtime/` локальны, не публикуются и не являются источником команд.
14. VLESS, VPN, Outline, Tailscale и другие сетевые технологии оформляются как отключаемые слои с режимами `off/observe/config-test/manual-window`. Автоматическая смена маршрута запрещена до отдельной приемки.
