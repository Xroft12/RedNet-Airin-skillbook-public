# Assets

`assets/` хранит только публично безопасные иллюстрации, схемы, скриншоты и визуальные материалы для GitHub-витрины REDNET Airin Skillbook.

## Правила безопасности

- без секретов, токенов, cookies, session-файлов и ключей;
- без личных данных, сырого чата, дневников и приватных PDF/капсул;
- без точных путей рабочей среды и закрытых сетевых адресов;
- без скриншотов, по которым можно восстановить приватный контур;
- для UI-превью использовать синтетические статусы и placeholders;
- если изображение получено из реального UI, перед добавлением проверять его глазами и не включать live-адреса/аккаунты/пути.

## Как добавлять новые изображения

1. Делать SVG/PNG как самостоятельную публичную схему, а не снимок внутренней среды.
2. Перед добавлением проверить изображение глазами и пройти `docs/privacy-boundary.md`.
3. Не включать runtime-состояния, реальные аккаунты, сетевые адреса и локальные пути.
4. Добавить строку в таблицу выше и ссылку из документа, где картинка используется.
5. Для скриншотов портала сначала поднять локальный сервер и проверить, что портал не выполняет live-команды.
