# REDNET Airin Grant Access Pack / Пакет заявок REDNET Airin

**Repository:** https://github.com/Xroft12/RedNet-Airin-skillbook-public  
**Status:** public-safe application package, no secrets, no personal data, no private runtime state.  
**Primary themes:** QMeta meta-skills, Airin/Hermes agent, defensive security automation, public-safe skillbook, read-only/dry-run tooling.

## RU — что это

Этот пакет нужен, чтобы представить REDNET Airin Skillbook как аккуратный open-source проект для получения официальных доступов, API credits, research support и security-oriented программ.

Главная позиция проекта:

> REDNET Airin Skillbook — публично-безопасная книга навыков и исследовательский каркас для агентных систем, где QMeta управляет ветвлением решений, аудитом, критериями, памятью процесса и безопасной кристаллизацией новых навыков.

Ключевой принцип публикации: в репозиторий попадают только очищенные материалы — архитектура, формулы, инструкции, синтетические примеры, SKILL.md, схемы, протоколы и заявки. Сырой чат, личные данные, рабочие контуры, токены, ключи, cookies, приватные пути и закрытые материалы не публикуются.

## EN — what this is

This package presents REDNET Airin Skillbook as a public-safe open-source project for official access programs, API credits, research support, and defensive-security grants.

Core positioning:

> REDNET Airin Skillbook is a public-safe skillbook and research framework for agent systems where QMeta coordinates decision branching, audit, quality criteria, process memory, and safe crystallization of reusable skills.

Publication rule: only sanitized artifacts are committed — architecture, formulas, instructions, synthetic examples, SKILL.md files, diagrams, protocols, and grant drafts. Raw chats, personal data, live runtime state, tokens, keys, cookies, private paths, and sensitive materials are excluded.
