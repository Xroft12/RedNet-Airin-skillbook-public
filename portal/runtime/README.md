# Runtime-статусы портала

Эта папка предназначена для локальных, не публикуемых статусов выполнения.

Файл `docker-status.local.js` создаётся скриптом `scripts/export-docker-status.ps1` и подключается порталом только при явном открытии с `?runtime=local`, например `http://127.0.0.1:8795/?runtime=local#admin`. В Git попадает только этот README и безопасный пример.

Правила:

- `*.local.js` не публикуется;
- реальные адреса, порты, токены, имена контейнеров и приватные статусы должны редактироваться перед любым публичным скриншотом;
- портал остаётся read-only и не выполняет команды.
