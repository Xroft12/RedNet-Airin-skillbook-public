# RedNET Quiet Step Lab — процесс научной охоты

## 1. Роли первой академии

- **Архивариус компактности** — compression, CDC/CAS, succinct structures, procedural generation.
- **Математик тонких рычагов** — sketching, random projections, tensor/low-rank, HDC, filters, Bayesian state.
- **Инженер AI-связок** — quantization, routers, caches, local RAG, nano-sensors, SQLite ledgers.
- **Совет** — аналитические матрицы, которые проверяют классы мышления, но не имитируют людей.
- **Протоколист** — ведёт ledger, версии, статусы, evidence, риски.
- **Сборщик модулей** — превращает лучшие находки сессии в module packs под конкретного агента, роль или решение.
- **Разделчик трофеев** — режет добычу на принцип, экономию, failure modes, verifier, pilot и публикационный слой.
- **Локализатор** — держит RU/EN пару публичных материалов: смысл сохраняется, безопасность и границы совпадают.
- **Хранитель безопасности** — следит за секретами, self-training, приватностью и публикацией.

Каждому сабу напоминается: его модель должна принести не пересказ, а добычу — один принцип, который может изменить экономику RedNET.

## 2. Формула добычи

Каждая находка должна отвечать:

1. **Что это?** Алгоритм, формула, структура данных, паттерн, протокол.
2. **Почему это изящно?** Какой простой/тонкий инвариант даёт выигрыш.
3. **Что экономит?** RAM, CPU, latency, bandwidth, токены, внимание, риск.
4. **Где ломается?** Условия, при которых идея опасна или бесполезна.
5. **Evidence handle.** Paper/repo/standard/project/path/test. Если не проверено — `requires_verification`.
6. **RedNET adaptation.** Как применить у нас: Windows Hermes, Ubuntu edge, NAS, SQLite, KB/RAG, sensors, Telegram/cron.
7. **Experiment.** Минимальный прототип без GPU/платных API.
8. **Council status.** `pilot_now`, `audit_first`, `scout`, `red_zone`.

## 3. Совет: обязательная классификация

- `pilot_now` — можно проверять локально и безопасно сейчас.
- `audit_first` — полезно, но нужна безопасность/приватность/runtime-аудит.
- `scout` — концептуально ценно, но пока исследование.
- `red_zone` — текущая реализация опасна/хрупка; принцип можно сохранить отдельно.

## 4. Главный инженерный принцип

```text
cheap deterministic sensor
  -> compact sketch/filter/cache
  -> candidate retrieval
  -> exact verifier / small model
  -> large model only when needed
  -> human/Guardian for risky actions
```

Вероятностные и сжатые структуры не принимают окончательные решения. Они уменьшают пространство поиска.

## 5. Хранение

- `locales/` — RU/EN миссия и публичная языковая рамка.
- `workspace/` — слои рабочего пространства лаборатории.
- `pipelines/` — повторяемые процессы охоты, добычи, разделки и трофеев.
- `inbox/` — Markdown-карточки сабов.
- `data/discoveries.jsonl` — append-only поток событий, пригодный для NAS/GitHub diff.
- `data/discoveries.sqlite3` — query layer для совета, отчётов и будущих dashboards.
- `reports/` — дайджесты волн.
- `backlog/` — проверочные эксперименты.
- `council/` — результаты Совета и двойной оценки.
- `modules/` — индивидуальные пакеты под агента/роль/решение, собранные из лучших находок.

## 5.1. Автономный цикл

Подробный регламент хранится в `pipelines/HUNT-HARVEST-CARVE-TROPHIES.ru.md` и английской паре `pipelines/HUNT-HARVEST-CARVE-TROPHIES.en.md`.

Минимальная формула:

```text
охота -> добыча -> разделка -> трофеи -> пилоты -> библиотека -> новая охота
```

Трофей считается настоящим только если он стал reusable capability: module pack, eval, script, article, dataset-lite, роль или повторяемая практика.

## 6. GitHub + NAS

- GitHub-вариант: только очищенная библиотека без приватных raw logs и секретов.
- NAS-вариант: рабочее зеркало и архив, но тоже без raw secrets.
- Для NAS-монтажа использовать явный путь, проверять доступность перед копированием.
- Секретные источники не включать в mirror.

## 7. Метрики отличия сабов

Саб считается отличившимся, если он принёс:

- принцип, который можно проверить локально;
- экономию через измеримую метрику;
- честные ограничения;
- связь с нашей архитектурой;
- прототип, который можно поставить в backlog.

Лучший саб/роль первой охоты становится кандидатом в постоянную научную группу лаборатории.
