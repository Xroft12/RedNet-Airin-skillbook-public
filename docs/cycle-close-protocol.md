# Протокол закрытия цикла разработки

Этот протокол фиксирует обязательное правило проекта REDNET Airin Skillbook: цикл разработки не считается завершенным, пока изменения не проверены, не упакованы, не сохранены локально, не выгружены в GitHub и не продублированы в резервный контур.

Протокол действует до полного завершения проекта. Он относится к репозиторию Skillbook и не управляет live Hermes, Айрин, Алетией, VPN, Tailscale, Ubuntu, EdgeRouter или рабочими сессиями.

## Что считается циклом

Цикл разработки - это любой проход, в котором менялись документы, навыки, протоколы, установочные пакеты, демо-сенсор, упаковка, отчеты или правила проекта.

Цикл закрывается только после пяти действий:

1. Проверки репозитория и пакетов.
2. Создания отчета закрытия цикла.
3. Создания локального снимка.
4. Копирования снимка в резервный контур.
5. Коммита и отправки в GitHub.

Если хотя бы один пункт не выполнен, следующая сессия должна начинаться с восстановления закрытия цикла, а не с новой разработки.

## Два контура выгрузки

### Очищенный контур

Очищенный контур - это GitHub-репозиторий Skillbook. В него входят:

- публичная документация;
- готовые skill-папки;
- протоколы сопровождения;
- безопасные установочные пакеты;
- демо-сенсор в режиме observe-only;
- отчеты закрытия цикла без секретов и внутренних путей.

### Служебный контур

Служебный контур - это локальный архив и NAS-копия. Он нужен для восстановления проекта после сбоя.

Даже в служебный контур не включаются живые секреты:

- токены;
- пароли;
- OAuth/Telegram-сессии;
- приватные ключи;
- сырой чат;
- дневниковые капсулы Айрин;
- восстановимые runtime-базы;
- payload сетевого трафика.

Если для восстановления нужны такие данные, они должны храниться в отдельном защищенном хранилище вне публичного Skillbook.

## Обязательные проверки

Перед закрытием цикла выполняются:

- `git status --short --branch`;
- `git diff --check`;
- проверка UTF-8 документов и manifest-файлов;
- поиск секретов по публичным корням;
- проверка Hermes manifest;
- проверка REDNET-схем и безопасных examples;
- проверка read-only границ портала;
- dry-run установщика;
- тесты сенсорного прототипа;
- проверка содержимого ZIP-архива;
- проверка SHA256 для архивов;
- проверка совпадения локального `HEAD` и `origin` после отправки;
- проверка SHA256 NAS-копии.

## Скрипт закрытия

Основной инструмент:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\cycle-close.ps1 -DryRun
```

`DryRun` выполняет проверки и показывает, что будет сделано, но не создает отчет, не архивирует, не копирует на NAS, не коммитит и не отправляет в GitHub.

Фактическое закрытие:

```powershell
$env:REDNET_SKILLBOOK_NAS_ROOT="<nas-root>\skillbook\cycles"
powershell -ExecutionPolicy Bypass -File scripts\cycle-close.ps1 -Apply
```

Реальный путь NAS задается оператором через переменную окружения или параметр `-NasRoot`. Он не хранится в публичной документации проекта.

## Режимы скрипта

| Режим | Что делает |
|---|---|
| `DryRun` | Только проверяет и показывает план действий. |
| `Apply` | Выполняет проверки, создает отчет, локальный архив, NAS-копию, коммит, push и финальную сверку. |

`Apply` запрещен без доступного резервного контура. Если NAS недоступен, цикл не считается закрытым.

## Артефакты цикла

После успешного `Apply` должны появиться:

- `reports/cycles/<timestamp>/cycle-close-report.md`;
- `reports/cycles/<timestamp>/artifacts-manifest.json`;
- `backups/cycles/<timestamp>/rednet-airin-skillbook-<timestamp>.zip`;
- `backups/cycles/<timestamp>/rednet-airin-skillbook-<timestamp>.zip.sha256`;
- NAS-копия архива, SHA и отчета;
- GitHub commit;
- успешная проверка `origin == HEAD`.

Папка `backups/` не публикуется в GitHub. Отчет в `reports/cycles/` должен быть публично безопасным.

## Запреты

Во время закрытия цикла нельзя:

- запускать штатный Hermes Desktop;
- нажимать Repair/Retry/Use local gateway в штатном клиенте;
- применять installer с `-Apply` к live Hermes без отдельного окна обслуживания;
- рестартовать Айрин или Алетию;
- менять VPN, Tailscale, маршруты, EdgeRouter, Ubuntu или firewall;
- публиковать сырой чат, личные дневники, капсулы, токены, сессии и закрытые адреса.

## Критерий завершения

Цикл закрыт только если:

- рабочее дерево Git чистое;
- `origin/master` совпадает с локальным `HEAD`;
- локальный архив создан;
- NAS-копия создана и SHA совпадает;
- отчет закрытия цикла создан;
- в отчете нет секретов и приватных данных.
