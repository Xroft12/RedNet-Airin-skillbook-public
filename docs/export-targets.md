# Реестр целей выгрузки

Этот документ описывает, куда должен выгружаться проект в конце каждого цикла разработки.

## Обязательные цели

| Цель | Назначение | Способ |
|---|---|---|
| Локальный репозиторий | Основная рабочая копия Skillbook | `<local-dev>\REDNET-AIRIN-SKILLBOOK` |
| GitHub `origin` | Очищенный репозиторий Skillbook | `git push origin master` |
| Локальный архив | Быстрое восстановление без сети | `backups/cycles/<timestamp>/` |
| NAS-копия | Резервная копия вне рабочего ПК | задается через `REDNET_SKILLBOOK_NAS_ROOT` |

## Правило приватности

В публичные файлы проекта не записываются реальные токены, пароли, сессии, приватные ключи и точные закрытые маршруты.

NAS-путь задается оператором во время выполнения:

```powershell
$env:REDNET_SKILLBOOK_NAS_ROOT="<nas-root>\skillbook\cycles"
```

Если фактический NAS-путь меняется, меняется только переменная окружения или параметр запуска, а не публичный репозиторий.

## Будущие цели

Допускается добавить второй приватный GitHub remote для служебных отчетов, если он будет создан отдельно от публичного Skillbook.

До появления такого remote обязательными остаются:

1. GitHub `origin`.
2. Локальный архив.
3. NAS-копия.
4. Отчет закрытия цикла.
