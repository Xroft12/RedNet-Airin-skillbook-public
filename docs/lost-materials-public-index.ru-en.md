## RU — восстановленные материалы для публичного слоя

### 1. QMeta Cognitive Nexus / Aletheia / QSF

Публично-безопасная линия исследований:

- `QMeta Cognitive Nexus` — практический пакет для режимов `answer`, `skill`, `consciousness_cycle`.
- `QMeta Subconscious Field (QSF)` — слой генерации скрытых альтернатив перед ответом.
- `Generate -> Evolve -> Collapse -> Gate -> Broadcast` — схема преобразования ветвей в итоговый результат.
- `Pre-Broadcast Jury` — независимая проверка перед публикацией ответа: relevance, grounding, contradiction, counterexample, artifact, calibration, utility.
- `metaerror = actual_error - expected_own_error` — принцип появления новых узлов и навыков из разницы между ожидаемой и фактической ошибкой.
- `ConsciousPacket` — публично-описуемый контейнер результата: candidate, confidence, assumptions, risks, invariants, counterexample, provenance, iteration beacon.

Публичная граница: всё это описывается как инженерная модель контроля качества и не утверждает сознание, магию или физическое квантовое вычисление.
