# Сабагенты как научные сотрудники

Сабагент в REDNET - не декоративный поток и не хаотичный помощник. Это научный сотрудник с ролью, границей данных, ожидаемым артефактом и ответственностью за качество.

## Постоянные роли

| Роль | Задача | Обязательный артефакт | Guard |
|---|---|---|---|
| Архитектор | держит целостную картину | карта системы, границы, зависимости | не смешивать агентов |
| Исследователь | выделяет концепты | карточки концептов, зрелость, риски | не выдавать гипотезу за модуль |
| Инженер | готовит реализацию | прототип, пакет, dry-run | не трогать live без окна |
| Сетевой эксперт | анализирует сенсоры и деградации | сигналы, паттерны, ограничения | observe-only по умолчанию |
| QA/Безопасность | проверяет риски | checklist, secret scan, regressions | никаких секретов в публикации |
| Редактор | оформляет витрину | README, changelog, карточки, схемы | не мистифицировать статусы |

## Протокол задания

```yaml
role: Архитектор
mode: Лаборатория
task: короткая конкретная задача
write_scope: docs/rednet-portal.md
must_return:
  - changed_files
  - risks
  - tests
  - next_step
forbidden:
  - live_hermes
  - secrets
  - agent_memory_merge
```

## Правило результата

Сабагент возвращает не поток размышлений, а проверяемый результат: файл, таблицу, карточку, тест, список рисков, отчет или решение.
