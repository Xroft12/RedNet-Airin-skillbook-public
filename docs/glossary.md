# Словарь REDNET Airin Skillbook

Словарь нужен, чтобы публичная документация не смешивала русский текст, технические aliases и внутренние названия.

| Термин | Alias | Как использовать публично |
|---|---|---|
| Skillbook | книга навыков | Репозиторий как навигационная книга: docs, skills, protocols, packages, portal. |
| Навык | skill / `SKILL.md` | Установочный модуль с назначением, режимами, границами и проверкой. |
| Мета-навык | meta-skill | Навык, который улучшает процесс мышления/работы агента: критерии, неопределённость, публичное редактирование. |
| Контур | contour | Изолированная роль или слой работы агента. Не равен человеку и не получает чужую память. |
| Режим только чтения | read-only | UI/портал/скрипт показывает состояние, но не выполняет live-команды. |
| Наблюдение | observe | Режим анализа и рекомендаций без действия. |
| Рекомендация | advise | Модуль создаёт pending-рекомендацию, но не меняет систему сам. |
| Удержание | hold | Stop-gate: действие откладывается до проверки или явного окна обслуживания. |
| Окно обслуживания | maintenance window | Отдельно подтверждённое время/контекст для live-изменений. |
| Сначала черновик | draft-first | Внешний канал получает только черновик до ручной проверки. |
| Публичная витрина | public surface | Обезличенные docs/assets/portal без приватного корпуса. |
| Приватный контур | private contour | Raw чаты, дневники, runtime-состояния, токены, рабочие базы и восстановимые настройки. |
| Проверочный запуск | dry-run | Команда показывает план изменений и ничего не копирует/не меняет. |
| Прототип наблюдения | observe-only prototype | Учебный/локальный код, который работает на synthetic/replay данных и не выполняет live-действия. |
| Curated report | очищенный отчёт | Ручная публичная сводка без raw inbox, ledger, личных фрагментов и приватных путей. |
| Raw inbox / ledger | рабочий сырой слой | Не публикуется. Может быть заменён curated report или module pack. |

## Правило имён

- `Airin / Айрин` допустимо как имя публичного проекта/агентного образа.
- Имена операторов, частные роли семьи/друзей и персональные обстоятельства заменяются на `оператор`, `ревьюер`, `контрибьютор`, `владелец проекта`, если только имя не является осознанной публичной частью проекта.
- `Aletia / Алетия`, `Марсель` и другие контуры описываются как роли/контуры, без переноса личной памяти и без приватных деталей.

## Правило языков

- Пользовательские разделы ведём по-русски.
- Английские aliases оставляем в скобках или в коде там, где это термин Hermes, GitHub, JSON Schema, PowerShell или API.
- Не смешиваем в одном заголовке русский и английский без необходимости.
