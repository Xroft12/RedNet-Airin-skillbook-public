# Локальный резервный чат

Локальный резервный чат - это отдельный канал связи с агентом на той же машине или в доверенной локальной среде. Он нужен, когда внешний канал недоступен, но пользователь должен сохранить прямой контакт с системой.

## Назначение

Локальный чат решает практическую проблему: после сбоя связи агент не должен выглядеть так, будто он "проснулся без памяти". Резервный канал помогает:

- принять сообщение без Telegram;
- сохранить локальную историю;
- показать статус;
- удержать очередь;
- не дергать внешнюю доставку без необходимости;
- дать человеку рабочую точку входа во время деградации.

## Безопасный режим

Базовый режим:

```text
bind_host=127.0.0.1
external_delivery=disabled_by_default
mode=local
```

Это означает, что интерфейс доступен только с локальной машины, а внешняя отправка не выполняется автоматически.

## Минимальный API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/health` | Проверка живости |
| `GET` | `/api/status` | Статус, режим, очередь, счетчики |
| `POST` | `/api/chat` | Отправить локальное сообщение |
| `GET` | `/api/history` | Получить локальную историю |
| `GET` | `/api/queue` | Посмотреть удержанные и ожидающие сообщения |
| `POST` | `/api/hotoff` | Включить или выключить удержание |

## Связь с Guardian

Guardian может рекомендовать локальный чат, когда:

- внешний канал деградировал;
- очередь близка к пределу;
- OAuth или сетевой маршрут нестабилен;
- отправка наружу может ухудшить состояние;
- нужно удержать ответ до восстановления связи.

Важно: локальный чат сам не меняет сеть, не переключает VPN и не выполняет ремонт. Он только дает надежный канал ввода-вывода и безопасную точку управления.

## Режимы

| Режим | Значение |
|---|---|
| `off` | Канал выключен |
| `local` | Работает только локально |
| `observe` | Показывает статус и историю |
| `hold` | Принимает сообщения, но удерживает внешнюю доставку |
| `incident` | Используется как аварийная точка связи |

## Данные

Локальный чат может хранить:

- время сообщения;
- роль отправителя;
- текст локального сообщения;
- статус доставки;
- очередь;
- причину удержания.

Он не должен показывать:

- токены;
- session-файлы;
- содержимое `.env`;
- приватные ключи;
- полные трассировки с секретами.

## Критерии готовности

Локальный чат готов к использованию, если:

- `/health` возвращает `ok=true`;
- главная страница открывается;
- сообщение сохраняется в локальной истории;
- очередь видна;
- hot-off переключается без перезапуска основного агента;
- внешний канал не дергается по умолчанию;
- интерфейс не ломает Telegram и основную рабочую среду.
