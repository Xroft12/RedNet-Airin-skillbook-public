# Интеграция QMeta с Айрин

QMeta подключается к Айрин как отключаемый инструментальный слой. Он не заменяет личность, память или основной диалоговый контур агента. Его задача — давать проверяемые режимы анализа, кристаллизации навыков, оценки ветвей и восстановления процесса.

## Режимы

| Режим | Назначение | Побочные эффекты |
|---|---|---|
| `off` | слой выключен | отсутствуют |
| `observe` | анализирует запросы и строит диагностику | только журнал |
| `assist` | предлагает ветви, критерии и итоговый ответ | ответ через основной агент |
| `skill` | кристаллизует повторяемый навык | создает skill-card в рабочей зоне |
| `publish` | готовит очищенные материалы | только публичный контур |

Первый включаемый режим для Айрин: `observe`. Режим `skill` включается только в сервисном окне или через явную команду.

## MCP-инструменты

Пакет `hermes-airin-qmeta` добавляет optional MCP-сервер:

```bash
cd packages/qmeta/rednet-airin-qmeta
pip install -e ".[mcp]"
hermes-airin-mcp
```

Команды выше выполняются из корня репозитория Skillbook. Если ты уже находишься в папке `packages/qmeta/rednet-airin-qmeta`, команду `cd ...` выполнять не нужно.

Инструменты:

- `solve` — запускает QMeta в режиме `answer` или `skill`;
- `skill_catalog` — возвращает встроенный каталог мета-навыков;
- `explain_model` — объясняет научную границу и операторную модель.

MCP-слой не хранит токены, OAuth, Telegram-сессии, сырой чат или личную память Айрин. Если указан `memory_path`, он пишет только JSONL-результаты QMeta в заданный файл.

## Skillbook-адаптация

QMeta представлен двумя уровнями:

- библиотека: `packages/qmeta/rednet-airin-qmeta`;
- навык: `skills/rednet-meta/rednet-qmeta-branching-engine`.

Навык используется как протокол включения: когда применять QMeta, какие входные данные нужны, как проверить результат и как отключить слой.

## Контроль безопасности

Ни один режим QMeta не должен:

- запускать Hermes Desktop;
- менять сеть, VPN, Docker, Telegram или OAuth;
- читать личные капсулы и дневники без явного указания;
- публиковать приватные материалы;
- выполнять скрытые действия.

Все сильные концепты переводятся в безопасную форму: симуляция, оценка, журнал, рекомендация, кристаллизация навыка.
