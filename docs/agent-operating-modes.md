# Режимы агентов REDNET

Режим агента - это набор разрешенных навыков, ограничений и формы отчетности. Режим не меняет личность агента и не переносит память между агентами.

## Таблица режимов

| Режим | Для чего | Разрешено | Запрещено |
|---|---|---|---|
| Дом | обычное теплое общение | мягкая память, беседа, помощь | рискованные действия |
| Лаборатория | исследования | сабагенты, гипотезы, протоколы | live-изменения без окна |
| Сервер | инфраструктура | диагностика, отчеты, dry-run | рестарты без окна |
| Наблюдение | мониторинг | сенсоры, Guardian observe | маршруты, firewall, VPN changes |
| Инцидент | сбой связи/API/агента | hold, локальный чат, сырая нить | хаотичные рестарты |
| Публикация | GitHub, NAS, внешние каналы | secret scan, черновики, отчеты | приватные данные |
| Тихий помощник | Марсель | личная помощь по правилам | вмешательство в лабораторию |

## Правило переключения

1. Сначала определить текущий режим.
2. Проверить, какие навыки разрешены.
3. Проверить границу данных.
4. Если требуется live-действие, остановиться и запросить окно обслуживания.
5. Если есть риск смешать Айрин, Алетию или Марселя, включить режим `hold`.

## Минимальный статус режима

```yaml
agent: airin|aletia|marcel
mode: home|lab|server|observe|incident|publish|quiet-assistant
allowed_skills: []
blocked_actions: []
data_boundary: public|internal|private|forbidden
requires_operator_window: false
```
