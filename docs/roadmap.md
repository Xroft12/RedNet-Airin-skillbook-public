# Дорожная карта

Это дорожная карта именно публичной витрины. Она не подменяет ремонт Айрин и не должна отвлекать от P0-работ.

## Этап 1. Публичный каркас

Цель:

- сделать понятный `README.md`;
- зафиксировать границу приватности;
- описать навыки и мета-навыки в таблицах;
- связать всё с существующими аналитическими материалами.

Результат:

- репозиторий читается как законченная книга навыков;
- видно, что публично, а что скрыто;
- есть маршрут для быстрого входа.

## Этап 2. Публичная инженерная рамка

Цель:

- описать архитектуру без рабочей среды;
- оформить исследовательские заметки;
- зафиксировать troubleshooting и ограничения;
- подготовить релизные заметки понятным языком.

Результат:

- материал можно использовать как публичный инженерный отчёт;
- витрина не обещает больше, чем подтверждено.

## Этап 3. Упаковка и релизы

Цель:

- подготовить ссылки на будущие публичные пакеты;
- оформить правила публикации;
- не смешивать публичные и приватные артефакты.

Результат:

- можно добавлять GitHub Releases или архивы без перестройки структуры.

## Этап 4. Возможный интерфейсный слой

Цель:

- если появится отдельная задача на панель, рассмотреть Quasar / Vue как будущий кандидат;
- сделать будущую витрину для статусов, навыков и релизных заметок;
- не вмешивать это в текущий ремонт Айрин.

Статус:

- не P0;
- только будущий кандидат;
- реализовывать отдельно, когда это не мешает основному контуру.

## Этап 5. Проверка перед публикацией

Перед релизом нужно вручную проверить:

- отсутствие секретов;
- отсутствие сырого корпуса чатов;
- отсутствие приватных PDF и капсул;
- отсутствие ссылок на рабочую среду Hermes;
- корректность всех ссылок;
- безопасность SVG и markdown-диаграмм;
- соответствие `CHANGELOG.md` реальному составу репозитория.

## Что считается готовностью

| Критерий | Что должно быть |
|---|---|
| Публичность | Нет секретов и приватных выгрузок |
| Читаемость | README ведёт к нужным документам за несколько кликов |
| Проверяемость | Есть таблицы, схемы и релизные заметки |
| Безопасность | Есть boundary doc и `.gitignore` |
| Реализм | Quasar/Vue описан как будущий кандидат, а не как готовый стек |
