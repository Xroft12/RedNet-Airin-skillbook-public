# QMeta / Airin grant positioning — RU / EN

> Public-safe research positioning for grant and access applications. This document is intentionally bilingual so reviewers can evaluate the project without access to private REDNET/Hermes infrastructure.

## RU — краткая формулировка

**REDNET Airin Skillbook** — публично-безопасная книга навыков и исследовательский каркас для агентных контуров Airin/Hermes. Основа проекта — **QMeta**, классическая инженерная модель мета-навыков: ветвление гипотез, аудит рисков, экспертный совет, усиление согласованных решений, измерение результата и кристаллизация повторно используемых навыков.

Проект не утверждает физическое квантовое вычисление, наличие сознания у модели или нелокальные эффекты. Квантово-информационные термины используются только как инженерные аналогии для ансамблевой оценки, коррекции ошибок, пороговых режимов и трассируемой памяти решений.

### Цель

Создать открытый, воспроизводимый и безопасный набор навыков, протоколов и библиотек для:

- повышения качества длинных агентных сессий;
- безопасной разработки и ревью open-source кода;
- defensive security review для WordPress/PWA/DevOps-контуров;
- работы с ошибками, деградацией контекста и восстановлением процесса;
- превращения удачных стратегий в installable skills без публикации личных данных.

### Ключевой оператор QMeta

```text
branching -> audit -> score -> council -> interference -> measure -> answer | skill
```

Мета-навык не просто отвечает на запрос, а меняет конфигурацию процесса: критерии качества, уровень осторожности, память, режим проверки, ветвление и журнал причин решения.

### Почему это полезно грантодателю

1. **Open source maintainability.** Проект превращает неструктурированные агентные практики в проверяемые skill-карточки, README, тесты и инструкции.
2. **Cyber defense.** Встроенная модель `deny-by-default`, safe simulation, permission-check и privacy boundary снижает риск небезопасных действий.
3. **Research value.** QMeta формализует наблюдаемые эффекты: удержание контекста, отделение факта от гипотезы, continuity после сбоя, повторное использование удачных ветвей.
4. **Low-resource orientation.** Quiet Step Lab ищет малоресурсные алгоритмы, компрессию, каскады микромоделей и методы экономии контекста.
5. **Public/private boundary.** Репозиторий специально очищен от токенов, raw-памяти, live-инфраструктуры, персональных данных и приватных журналов.

### Планируемые результаты при получении доступа/API credits

- добавить eval-наборы для meta-skills и safe cyber review;

- улучшить bilingual documentation;
- добавить synthetic examples и red-team/blue-team acceptance checklists;
- провести измеримые эксперименты по снижению ошибок процесса и затрат контекста.

## EN — reviewer-facing summary

**REDNET Airin Skillbook** is a public-safe skillbook and research scaffold for Airin/Hermes agent workflows. Its core is **QMeta**, a classical engineering model for meta-skills: hypothesis branching, risk audit, expert-council scoring, reinforcement of convergent branches, final measurement, and crystallization of reusable skills.

The project does not claim physical quantum computation, model consciousness, magic, or non-local effects. Quantum-information language is used only as an engineering analogy for ensemble evaluation, error correction, threshold behavior, and traceable decision memory.

### Goal

Build an open, reproducible, safety-first set of skills, protocols, and libraries for:

- improving long-running agent workflows;
- safe open-source code development and review;
- defensive security review for WordPress/PWA/DevOps environments;
- handling context degradation, process recovery, and error correction;
- converting successful strategies into installable skills without publishing private data.

### QMeta operator

```text
branching -> audit -> score -> council -> interference -> measure -> answer | skill
```

A meta-skill does not merely answer a prompt. It changes the process configuration: quality criteria, caution level, memory, verification mode, branch structure, and the decision trace.

### Why this matters for grant reviewers

1. **Open-source maintainability.** The project converts informal agent practices into auditable skill cards, README files, tests, and instructions.
2. **Cyber defense.** The built-in `deny-by-default`, safe-simulation, permission-check, and privacy-boundary model reduces unsafe side effects.
3. **Research value.** QMeta formalizes observable workflow effects: context retention, fact/hypothesis separation, continuity after failure, and reusable successful branches.
4. **Low-resource orientation.** Quiet Step Lab focuses on low-resource algorithms, compression, micro-model cascades, and context-cost reduction.
5. **Public/private boundary.** This repository is intentionally sanitized: no tokens, raw memory, live infrastructure, personal data, or private logs.

### Planned outcomes if API/model access is granted

- expand the QMeta Python/MCP package;
- add evaluation sets for meta-skills and safe cyber review;
- prepare demonstrators for WordPress/PWA security review;
- improve bilingual documentation;
- add synthetic examples and red-team/blue-team acceptance checklists;
- run measurable experiments on workflow error reduction and context-cost savings.

## Safe claim boundary

Allowed public claim:

> QMeta is a classical engineering model for branching agent workflows, inspired by error correction, ensemble evaluation, threshold behavior, and auditable decision traces.

Not allowed in public grant materials:

- claims of physical quantum computation;
- claims of model consciousness as fact;
- raw private chats, personal histories, names, tokens, live endpoints;
- instructions for unauthorized cyber activity;
- hidden or autonomous actions outside explicit permission gates.
