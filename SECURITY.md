# Public safety policy

REDNET Airin Skillbook is a public documentation, research and skillbook repository.

## Public scope

The public scope includes:

- synthetic examples;
- documentation;
- public diagrams;
- installable skill cards;
- read-only portal materials;
- evaluation prompts and checklists.

## Out of scope

The public repository must not include:

- local runtime exports;
- personal material;
- private operational configuration;
- credentials or access material.

## Reporting

Open a GitHub issue for public documentation problems.

For anything that may expose non-public material, contact the repository maintainer outside public issues.

## Default rule

When in doubt, keep material out of the public repository until reviewed.
