# Source mapping

Пакет собран по концептуальной линии RedNet / Xroft:

- QMeta Multiverse Engine v0.2.0: два режима `answer` и `skill`, ветви, амплитуды, интерференция, измерение, skill crystallization.
- Научная работа по мета-навыкам: память, наблюдатель, неопределенность, критерии, процессные следы, синхронизация веток.
- Айрин 2.0: Святилище, Совет Гениев, мета-подсети, Страж, Красная сеть, хроно-модели — переведены в инженерные безопасные абстракции.

Научная граница: QMeta — классический алгоритм. Квантовая терминология используется как язык архитектуры и метафора проектирования.
