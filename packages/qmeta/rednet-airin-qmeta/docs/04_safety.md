# Безопасность

Библиотека намеренно не содержит функций скрытого доступа, сканирования чужих систем, эксфильтрации, обхода защит, эксплуатации уязвимостей или автономных внешних действий.

## Принципы

1. Deny-by-default.
2. Permission-check перед инструментами.
3. Simulation-only для опасных концептов.
4. Human review для high/critical risk.
5. Журналирование действий и решений.
6. Минимизация побочных эффектов.

## Страж

`StrazhDoctrine` — policy engine. Он классифицирует событие и рекомендует:

```text
observe -> analyze -> recommend -> log
```

или для серьёзного риска:

```text
de-escalate -> verify evidence -> request permission -> act minimally -> log
```

## Красная сеть

В этой библиотеке «Красная сеть» — не сеть управления внешними системами. Это симуляционный контур аварийного допуска, выбора оператора, журнала и оценки необходимости вмешательства.
