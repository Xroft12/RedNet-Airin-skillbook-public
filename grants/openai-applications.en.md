## 4. Researcher Access Program

**Research title:** QMeta: Evaluating meta-skills for safer long-running agent workflows

**Research question**

Can a classical meta-skill framework reduce process errors in long-running agent sessions by making branching, risk review, criteria tracking, memory hygiene and answer/skill crystallization explicit and measurable?

**Project description**

QMeta models an agent workflow as a sequence of auditable operators: branching, review, scoring, council evaluation, reinforcement of compatible branches, measurement and output as either an answer or a reusable skill. We will evaluate whether this structure improves fact/hypothesis separation, continuity after interruption, privacy-boundary compliance and repeatability of complex development tasks.

**Method**

- Build synthetic tasks around documentation, code review, release preparation and safety-first maintainer workflows.
- Compare baseline single-pass answers with QMeta-guided multi-branch answers.
- Track task accuracy, consistency, boundary violations, latency/cost and auditability.
- Publish sanitized prompts, evaluation criteria and aggregate results.

**Expected outcomes**

- Bilingual research note.
- Reusable QMeta evaluation prompts.
- Improved public QMeta package documentation.
- Evidence-based recommendations for safe meta-skill design.
- Public-safe examples for open-source maintainers.
