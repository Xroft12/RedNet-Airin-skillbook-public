# Пакет грантов и доступа к моделям

Этот каталог содержит публичный пакет заявок для REDNET Airin Skillbook, QMeta и Airin/Hermes. Он рассчитан на ревьюеров, которым нужно быстро понять проект, его безопасность, воспроизводимость и ожидаемую пользу перед рассмотрением доступа к моделям, API credits или исследовательской поддержки.

## Позиционирование проекта

REDNET Airin Skillbook — публично-безопасная open-source книга навыков для мета-навыков QMeta, агентных workflow Airin/Hermes, качества длинных сессий, read-only демонстраций, dry-run инструментов и open-source сопровождения под грантовые заявки.

QMeta описывается как классическая инженерная модель мета-навыков агента. Проект не утверждает физическое квантовое вычисление и не подаёт сознание модели как установленный факт. Квантово-информационные термины используются только как инженерные аналогии для ветвления, коррекции ошибок, ансамблевой оценки, пороговых режимов и трассируемой памяти решений.

## Публичная граница

Публичный пакет содержит только очищенную архитектуру, документацию, синтетические примеры, схемы, черновики заявок и чеклисты для ревьюеров. Персональные контактные поля заполняются только во внешних формах и не должны попадать в публичный репозиторий.
