### Submission checklist

1. Make sure repository visibility is public and no closed material remains.
2. Confirm the public/private boundary in `docs/privacy-boundary.md`.
3. Use the English text first for foreign providers; keep the Russian version for internal review.
4. Replace placeholder contact fields with official applicant data.
5. Attach only sanitized diagrams, screenshots and public repository links.
6. Do not attach raw chats, closed archives, personal data, `.env`, access keys or infrastructure details.
