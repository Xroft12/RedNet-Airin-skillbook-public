# Submission checklist

## Before submitting

### Repository

- [ ] The repository is public and accessible.
- [ ] The root README points to separate English and Russian descriptions.
- [ ] New visual assets are available in `assets/`.
- [ ] Grant pages have no broken links.
- [ ] The privacy boundary is clear.
- [ ] Closed archive material is represented only as sanitized summaries.
- [ ] No personal data or access material is committed.

### Attach to applications

- [ ] Repository link.
- [ ] English README link.
- [ ] QMeta grant positioning link.
- [ ] QMeta scientific model link.
- [ ] Privacy boundary link.
- [ ] One or two SVG diagrams from `assets/`.
- [ ] Program-specific application text.
- [ ] Expected deliverables and a 3–6 month timeline.

### Do not attach

- [ ] Closed archives as-is.
- [ ] Raw private conversations.
- [ ] Local runtime exports.
- [ ] Personal records.
- [ ] Access keys or private infrastructure details.

## Recommended order

1. Codex for Open Source.
2. Codex Open Source Fund.
3. Trusted Access / defensive research support.
4. Researcher Access Program.
5. External providers and grant programs where eligibility matches.
