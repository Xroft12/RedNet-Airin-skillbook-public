# Submission checklist — RU / EN

## RU — перед подачей

### Публичный репозиторий

- [ ] Репозиторий открыт и доступен без приватных материалов.
- [ ] README объясняет проект за 30 секунд.
- [ ] Есть RU/EN формулировка для международных ревьюеров.
- [ ] Есть ссылка на QMeta positioning.
- [ ] Есть privacy boundary.
- [ ] Нет токенов, `.env`, cookies, raw logs, приватных путей, личных данных.
- [ ] Старые архивы просмотрены вручную: в публичный слой перенесены только обезличенные идеи.

### Что прикладывать к заявке

- [ ] Ссылка на репозиторий.
- [ ] Ссылка на `docs/qmeta-grant-positioning.ru-en.md`.
- [ ] Ссылка на `packages/qmeta/rednet-airin-qmeta/README.md`.
- [ ] 1–2 изображения или SVG-схемы из `assets/`.
- [ ] Краткий abstract на английском.
- [ ] Список planned deliverables.
- [ ] Честное указание, что использовался AI при подготовке, если форма спрашивает.

### Что не прикладывать

- [ ] Второй закрытый архив целиком.
- [ ] Сырые чаты и личные материалы.
- [ ] Рабочие базы, ключи, токены, endpoints, production paths.
- [ ] Материалы, где можно восстановить персональные данные.

## EN — before submitting

### Public repository

- [ ] Repository is public and contains no private materials.
- [ ] README explains the project in 30 seconds.
- [ ] RU/EN reviewer-facing positioning exists.
- [ ] QMeta positioning page exists.
- [ ] Privacy boundary exists.
- [ ] No tokens, `.env`, cookies, raw logs, private paths, or personal data.
- [ ] Old archives were reviewed manually; only sanitized ideas were moved to the public layer.

### Attach to applications

- [ ] Repository link.
- [ ] Link to `docs/qmeta-grant-positioning.ru-en.md`.
- [ ] Link to `packages/qmeta/rednet-airin-qmeta/README.md`.
- [ ] 1–2 public SVG diagrams from `assets/`.
- [ ] Short English abstract.
- [ ] Planned deliverables.
- [ ] Honest note about AI assistance if the form asks.

### Do not attach

- [ ] The closed archive as-is.
- [ ] Raw chats or personal materials.
- [ ] Production databases, access keys, endpoints, or private paths.
- [ ] Any material that can reconstruct personal data.

## Suggested submission sequence

1. OpenAI Codex for Open Source.
2. OpenAI Cybersecurity Grant / Trusted Access for Cyber.
3. OpenAI Researcher Access Program.
4. Google AI Studio / Gemini API setup.
5. GitHub Models setup in this repository.
6. Cloudflare Workers AI setup for low-cost experiments.
7. Startup credit applications only after entity/startup positioning is ready.
8. NLnet/NGI/OTF only when the open call scope matches the project.
