# Чеклист подачи

## Перед подачей

### Репозиторий

- [ ] Репозиторий публичный и доступен без авторизации.
- [ ] Корневой README ведёт на отдельные русскую и английскую версии описания.
- [ ] Новые визуальные материалы доступны в `assets/`.
- [ ] В grant-страницах нет битых ссылок.
- [ ] Граница приватности описана ясно.
- [ ] Материалы закрытого архива представлены только как очищенные сводки.
- [ ] В репозиторий не добавлены персональные данные или access material.

### Что прикладывать к заявкам

- [ ] Ссылка на репозиторий.
- [ ] Ссылка на английский README.
- [ ] Ссылка на QMeta grant positioning.
- [ ] Ссылка на QMeta scientific model.
- [ ] Ссылка на privacy boundary.
- [ ] Одна-две SVG-схемы из `assets/`.
- [ ] Текст заявки под конкретную программу.
- [ ] Ожидаемые результаты и timeline на 3–6 месяцев.

### Что не прикладывать

- [ ] Закрытые архивы как есть.
- [ ] Сырые приватные диалоги.
- [ ] Локальные runtime exports.
- [ ] Личные записи.
- [ ] Access keys или приватные детали инфраструктуры.

## Рекомендуемый порядок

1. Codex for Open Source.
2. Codex Open Source Fund.
3. Trusted Access / defensive research support.
4. Researcher Access Program.
5. Внешние провайдеры и грантовые программы, где проект подходит по условиям.
