# Grants and model access pack

This directory contains the public application package for REDNET Airin Skillbook, QMeta and Airin/Hermes. It is written for reviewers who need a clear, safe and reproducible overview of the project before considering model access, API credits or research support.

## Project positioning

REDNET Airin Skillbook is a public-safe open-source skillbook for QMeta meta-skills, Airin/Hermes agent workflows, long-running session quality, read-only demos, dry-run tooling and grant-ready open-source maintenance.

QMeta is presented as a classical engineering model for agent meta-skills. It does not claim physical quantum computation or model consciousness as a proven property. The project uses quantum-information language only as an engineering analogy for branching, error correction, ensemble evaluation, threshold behavior and traceable decision memory.
