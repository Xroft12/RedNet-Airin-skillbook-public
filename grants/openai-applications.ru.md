## 3. Trusted Access / defensive research support

**Название проекта:** AI-assisted defensive review and patch validation for open-source WordPress/PWA/DevOps components

**Репозиторий:** `https://github.com/Xroft12/RedNet-Airin-skillbook-public`

**Проблема**

Небольшим open-source сопровождающим и командам общественной инфраструктуры часто не хватает времени на системное ревью кода, релизное усиление и проверку документации. WordPress/PWA/DevOps проекты особенно чувствительны к ошибкам прав доступа, validation, escaping, update workflows, logging, file handling и release hygiene.

**Предлагаемая работа**

Мы будем использовать QMeta и мета-навыки Airin/Hermes для построения защитного workflow ревью open-source компонентов. Workflow будет формировать структурированные чеклисты, синтетические примеры, задачи patch validation и отчёты для ревьюеров. Фокус — prevention, remediation, maintainability и safe release practice.

**Что запрашиваем**

- API credits для defensive review experiments.
- Trusted access для качественного defensive analysis, если доступно.
- Model access для code review, patch validation, documentation review и оценки safety gates.

**Результаты**

1. Public-safe review protocol для WordPress/PWA/DevOps code.
2. QMeta evaluation prompts для risk classification и patch validation.
3. Синтетические обучающие примеры для проверки качества ревью.
4. Двуязычная документация и maintainer checklists.
5. Метрики: категории замечаний, false-positive notes, сэкономленное время, покрытие документации и полнота review trace.

## 4. Researcher Access Program

**Название исследования:** QMeta: Evaluating meta-skills for safer long-running agent workflows

**Исследовательский вопрос**

Может ли классический framework мета-навыков снижать ошибки процесса в длинных агентных сессиях за счёт явного ветвления, проверки рисков, отслеживания критериев, гигиены памяти и кристаллизации ответа/навыка?

**Описание проекта**

QMeta моделирует агентный workflow как последовательность проверяемых операторов: ветвление, review, scoring, council evaluation, усиление совместимых ветвей, measurement и выход либо как answer, либо как reusable skill. Мы оценим, улучшает ли эта структура разделение фактов и гипотез, continuity после interruption, compliance с privacy boundary и повторяемость сложных задач разработки.

**Метод**

- Создать синтетические задачи по документации, code review, release preparation и safety-first maintainer workflows.
- Сравнить baseline single-pass answers с QMeta-guided multi-branch answers.
- Измерять task accuracy, consistency, boundary violations, latency/cost и auditability.
- Публиковать только sanitized prompts, evaluation criteria и aggregate results.

**Ожидаемые результаты**

- Двуязычная research note.
- Reusable QMeta evaluation prompts.
- Улучшенная публичная документация QMeta package.
- Evidence-based recommendations для safe meta-skill design.
- Public-safe examples для open-source maintainers.
