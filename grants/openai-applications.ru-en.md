### RU — черновик заявки

**Project title:** AI-assisted defensive security review and patch validation for open-source WordPress/PWA/DevOps components

**Repository:** `https://github.com/Xroft12/RedNet-Airin-skillbook-public`

**Problem:**

Small open-source maintainers and public-service teams often lack enough time for systematic secure code review, release hardening, and documentation checks. WordPress/PWA/DevOps projects are especially exposed to issues around permissions, input validation, escaping, update workflows, logging, file handling, and release hygiene.

**Proposed work:**

We will use QMeta and Airin/Hermes meta-skills to build a defensive review workflow for open-source components. The workflow will produce structured checklists, synthetic examples, patch-validation tasks, and reviewer-facing reports. The focus is prevention and remediation, not offensive operations.

**Requested support:**

- API credits for defensive security review experiments;
- trusted access for high-quality defensive analysis where available;
- model access suitable for code review, patch validation, documentation review, and evaluation of safety gates.

**Deliverables:**

1. Public-safe security review protocol for WordPress/PWA/DevOps code.
2. QMeta evaluation prompts for risk classification and patch validation.
3. Synthetic vulnerable/fixed examples for education and testing.
4. Bilingual documentation and maintainer checklists.
5. Metrics: issue categories, false-positive notes, time saved, documentation coverage, and review trace completeness.

**Compliance statement:**

All work is defensive, permission-based, and limited to owned or explicitly authorized code. The public repository will not contain exploit instructions, credentials, private endpoints, or operational details.

## 3. Researcher Access Program

Application link: `https://openai.com/form/researcher-access-program/`

### RU — черновик заявки

**Research title:** QMeta: Evaluating meta-skills for safer long-running agent workflows

**Research question:**

Can a classical meta-skill framework reduce process errors in long-running agent sessions by making branching, risk audit, criteria tracking, memory hygiene, and answer/skill crystallization explicit and measurable?

**Project description:**

QMeta models an agent workflow as a sequence of auditable operators: branching, audit, scoring, council review, interference of compatible branches, measurement, and output as either an answer or a reusable skill. We will evaluate whether this structure improves fact/hypothesis separation, continuity after interruption, privacy-boundary compliance, and repeatability of complex development tasks.

**Method:**

- Build synthetic tasks around documentation, code review, release preparation, and security-safe maintainer workflows.
- Compare baseline single-pass answers with QMeta-guided multi-branch answers.
- Track task accuracy, consistency, safety-boundary violations, latency/cost, and auditability.
- Publish sanitized prompts, evaluation criteria, and aggregate results.

**Requested support:**

OpenAI API credits for running controlled experiments over publicly safe datasets and synthetic tasks.

**Expected outcomes:**

- Bilingual research note;
- reusable QMeta eval prompts;
- improved public QMeta package documentation;
- evidence-based recommendations for safe meta-skill design;
- public-safe examples for open-source maintainers.
