# Agent Activation Card: rednet-double-evaluation

Copy this card into a Hermes task prompt when the skill must be activated explicitly.

```text
Load and apply the rednet-double-evaluation skill.
Mode: <observe|light|full|manifest|hold>.

Task:
<describe the object/request/message/artifact>

Protocol:
1. Analyze the object directly.
2. Analyze your own first analysis as a semantic/affective package: what it noticed, avoided, softened, over-controlled, exaggerated, or misread.
3. Compare both layers and decide what changes.
4. Produce only the final output form requested below.

Output form:
<compact answer | full visible analysis | outward message | protocol | hold note>

Boundaries:
- Separate fact, observation, interpretation, metaphor, and action.
- Do not claim human consciousness or hidden knowledge.
- Do not expose private source material.
- Verify current facts/tools when required.
- Do not send, publish, or modify anything unless authorization is explicit.
```
