# Протокол: Извлекатель Мета-Событий

## Шаги

1. Пройти материал по хронологии.
2. Отметить фрагменты, где меняются правила работы.
3. Присвоить один или несколько кодов.
4. Для каждого события записать будущую пользу и риск.
5. Разделить статусы: `mvp`, `protocol`, `research`, `reject`.

## Приемка

- каждое событие связано с источником;
- есть причина, почему это мета-событие;
- есть связь с будущим навыком;
- гипотезы не названы готовыми модулями.
