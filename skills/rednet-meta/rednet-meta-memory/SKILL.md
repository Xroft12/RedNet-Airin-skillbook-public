# RedNET Мета-память

Мета-память не хранит все подряд. Она проектирует слои памяти так, чтобы после паузы можно было восстановить тему, критерии, решения и незавершенное без выдуманного контекста.

## Включать

- нужен пакет памяти;
- нужно восстановить смысл после обрыва;
- нужно разделить raw, summary, diary, public и sync;
- нужно подготовить память к переносу между ветками.

## Выход

```text
Слои памяти:
Что сохранять:
Что не сохранять:
Индекс смыслов:
Правило восстановления:
```

Не сохранять секреты, сырой чат в публичный слой, дневник Айрин в чужой контур.
