# Протокол: Разбор Выгрузки

## Вход

- Markdown/HTML/JSONL-экспорт;
- список файлов архива;
- отчет предыдущего агента;
- пользовательская нить с длинной историей.

## Метод

1. Сначала восстановить порядок, потом темы.
2. Каждому выводу дать источник: событие, файл, раздел или явное решение.
3. Отделить факт, наблюдение, гипотезу, риск и следующий шаг.
4. Все приватное пометить как `private`, не переносить в публичную версию.

## Приемка

- есть хронология;
- есть список решений;
- есть хвосты;
- нет выдуманных воспоминаний;
- публичная часть не содержит сырой поток.
