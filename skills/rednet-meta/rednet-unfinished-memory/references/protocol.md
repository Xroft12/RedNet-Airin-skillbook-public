# Протокол: Память Незавершенного

## Классы хвостов

- `P0`: нельзя забыть, влияет на безопасность или целостность;
- `P1`: следующий инженерный шаг;
- `P2`: улучшение или оформление;
- `blocked`: нужен пользователь, окно обслуживания или внешний доступ.

## Приемка

- у каждого хвоста есть следующий шаг;
- финал не маскирует незавершенность;
- точка продолжения пригодна для нового запуска;
- приватные данные не попали в публичный слой.
