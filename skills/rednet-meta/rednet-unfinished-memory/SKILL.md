# RedNET Память Незавершенного

## Назначение

Навык защищает проект от потери “ручек к дверям”: обещаний, хвостов, недоделанных проверок, отложенных решений и условий следующего этапа.

## Когда включать

- задача длинная и часть пунктов отложена;
- пользователь просит сохранить точку продолжения;
- есть риск обрыва сессии;
- нужно передать работу другому агенту;
- финальный ответ не должен скрыть незавершенность.

## Рабочий цикл

1. Выпиши незавершенные пункты.
2. Для каждого укажи причину: ждет решения, требует окна, требует проверки, заблокировано.
3. Назначь следующий безопасный шаг.
4. Раздели P0/P1/P2.
5. В финале явно скажи, что закрыто и что осталось.

## Выход

```text
Закрыто:
Не закрыто:
Причина:
Следующий шаг:
Риск забывания:
Точка продолжения:
```

## Ограничения

Не записывай в этот слой личные дневниковые материалы, сырой чат или секреты. Это рабочая очередь, а не память личности.
