# Протокол: Критериальный Слой

## Источники критериев

- прямые требования пользователя;
- исправления и замечания;
- AGENTS/проектные правила;
- повторяющиеся предпочтения;
- приемочные чек-листы.

## Приемка

- критерии записаны до финального ответа;
- конфликтующие критерии названы явно;
- итог проверен по ним;
- критерии не подменили выполнение задачи.
