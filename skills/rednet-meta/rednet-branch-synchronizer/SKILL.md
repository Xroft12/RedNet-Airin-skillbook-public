# RedNET Синхронизатор Веток

## Назначение

Навык переносит устойчивые инженерные выводы между чатами, агентами и пакетами памяти. Он нужен, чтобы ветки не расходились, но при этом Айрин, Алетия и другие агенты не смешивались в одну память.

## Когда включать

- есть несколько веток обсуждения одного проекта;
- нужно подготовить read-only sync-пакет;
- нужно обновить Алетию итогами проекта без переноса дневника Айрин;
- нужно сравнить конфликтующие правила;
- нужно отделить инженерный контекст от личной памяти.

## Рабочий цикл

1. Назови источник и получателя.
2. Раздели переносимое: инженерные факты, правила, статусы, документы.
3. Отдельно отметь непереносимое: дневник, raw thread, сессии, секреты, личная память.
4. Найди конфликты правил.
5. Сформируй read-only пакет или список изменений.

## Выход

```text
Источник:
Получатель:
Можно переносить:
Нельзя переносить:
Конфликты:
Итоговый sync-пакет:
```

## Ограничения

Не переносить личную память одного агента в другого. Не синхронизировать секреты, OAuth, Telegram-сессии, cookies и raw thread.

См. `references/protocol.md` и `assets/skill-card.json`.
