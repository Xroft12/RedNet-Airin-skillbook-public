# Протокол: Синхронизатор Веток

## Правило границ

Переносится только инженерный итог: документы, статусы, решения, приемочные критерии, открытые задачи. Не переносится личный дневник, сырой чат, runtime-сессии и приватные капсулы.

## Приемка

- источник и получатель названы;
- запрещенные данные явно исключены;
- конфликтующие правила помечены;
- пакет read-only;
- есть SHA/manifest, если создается архив.
