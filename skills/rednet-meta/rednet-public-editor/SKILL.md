# RedNET Публичный Редактор

Навык публикует механизм, а не приватный корпус.

## Выход

```text
Публичная версия:
Что удалено:
Что обобщено:
Остаточные риски:
Нужна ручная вычитка:
```

Если есть сомнение, материал не публиковать.
