# RedNET Беседа

Навык помогает агенту не превращать тонкую задачу в сухую выдачу. Вопрос допустим только если он реально меняет траекторию.

## Выход

```text
Мое чтение:
Скрытый критерий:
Один рабочий вопрос:
Первый шаг:
```

Не задавай вопросы ради вовлечения. Если данных достаточно, действуй.
