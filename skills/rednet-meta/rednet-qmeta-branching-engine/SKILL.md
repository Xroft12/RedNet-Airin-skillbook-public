# REDNET QMeta Branching Engine

## Назначение

Используй этот навык, когда задача требует не одного прямого ответа, а управляемого процесса:

- построить несколько проверяемых гипотез;
- отделить научный факт от метафоры и допущения;
- оценить риски и неопределенность;
- собрать итог через экспертные критерии;
- кристаллизовать повторяемый навык;
- оставить трассу причин решения.

## Рабочая граница

QMeta — классический программный слой. Он не является физическим квантовым вычислением и не делает утверждений о многомировом исполнении кода. Термины “ветвление”, “интерференция” и “измерение” используются как инженерные аналоги для ансамблевой оценки альтернатив.

## Режимы

- `off`: навык выключен.
- `observe`: строит диагностику, не меняя поведение агента.
- `assist`: предлагает ветви, критерии и итоговый ответ.
- `skill`: создает skill-card для повторяемого процесса.
- `publish`: готовит очищенный научный материал.

По умолчанию использовать `observe` или `assist`. Режим `skill` включать только при явном запросе.

## Протокол

Перед применением прочитай [protocol.md](references/protocol.md).

Минимальный цикл:

1. Зафиксировать запрос и цель.
2. Построить 3-7 ветвей решения.
3. Провести аудит безопасности и научной корректности.
4. Оценить ветви по полезности, риску, проверяемости и стоимости.
5. Синтезировать ответ или skill-card.
6. Сохранить трассу причин решения.

## Инструментальный слой

Python-пакет находится в:

```text
packages/qmeta/rednet-airin-qmeta
```

CLI:

```bash
hermes-airin "Собери проверяемую модель решения" --mode answer --json
```

MCP:

```bash
pip install -e ".[mcp]"
hermes-airin-mcp
```

## Отключение

Чтобы выключить слой, убери навык из активного профиля или установи режим `off`. Навык не должен держать фоновые процессы без явного запуска MCP-сервера.
