# RedNET Память Решений

Навык фиксирует договоренности, которые должны пережить текущую ветку: запреты, правила публикации, режимы, приемочные критерии.

## Выход

```text
Решение:
Источник:
Срок действия:
Где применять:
Где не применять:
Проверка актуальности:
```

Не записывай временную эмоцию или разовую правку как постоянное правило.
