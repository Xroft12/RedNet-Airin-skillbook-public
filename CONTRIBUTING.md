# Contributing

Thank you for considering a contribution to REDNET Airin Skillbook.

## Principles

- Keep examples synthetic.
- Keep RU and EN pages aligned where possible.
- Prefer dry-run examples before apply examples.
- Explain assumptions, limits and review steps.

## Good contributions

- Documentation improvements.
- Synthetic QMeta examples.
- Tests for public packages.
- Issue templates and reviewer checklists.
- Diagrams for the public documentation layer.

## Before opening a pull request

- Run available validation scripts.
- Check links from README and grants documentation.
- Avoid committing local runtime files.
- Avoid personal details.

## Pull request description

Please explain what changed, why it is useful and how to review it.
