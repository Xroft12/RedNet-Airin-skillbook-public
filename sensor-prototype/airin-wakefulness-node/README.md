# Airin Wakefulness Node

Observe-only прототип нано-узла для `rednet-wakefulness-cascade`.

Узел получает безопасный JSON snapshot, оценивает режим и пишет результат в SQLite. Он не вызывает LLM, не отправляет сообщения, не меняет сеть и не трогает live Hermes.

Внутреннее имя Layer 0: **Ари — Тихая Поступь**. Практический смысл: сначала научиться безопасно не действовать.

Версия `0.2` добавляет явный контур закрытия: каждый тик сохраняет нормализованный снимок, рекомендацию Guardian, ссылку на хэш нити при наличии и итоговое состояние закрытия. `no_op` считается успешным результатом, а не ошибкой или молчанием.

## Команды

```powershell
python wakefulness_node.py init --state-dir tmp\wake-demo
python wakefulness_node.py tick --state-dir tmp\wake-demo --snapshot samples\no-op.json --mode observe
python wakefulness_node.py summary --state-dir tmp\wake-demo
```

## Режимы

- `off` - вернуть выключенное состояние.
- `observe` - оценить snapshot без действий.
- `feel` - разрешить только пассивную отметку.
- `service` - вернуть диагностическую рекомендацию.
- `hold` - удерживать при риске.

## SQLite

Прототип создает таблицы:

- `wake_ticks` - совместимый журнал тиков.
- `wake_snapshots` - безопасные нормализованные признаки без содержимого сообщений.
- `wake_guardian_recommendations` - рекомендации без права исполнения.
- `wake_closures` - закрытие итерации и следующий безопасный интервал.
- `wake_thread_refs` - только хэш ссылки на нить, без сырого текста.
- `wake_audit` - технический аудит работы узла.

## Безопасность

Публичные samples не содержат payload, сырого чата, токенов, сессий, аудио или приватных путей.

Если snapshot содержит запрещенные поля, узел завершает ingest ошибкой.
