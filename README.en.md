## What is this?

**REDNET Airin Skillbook** is a public-safe repository for Airin/Hermes agent skills, QMeta meta-skill research, dry-run installers, read-only portal documentation, and defensive-security workflows.

It is not a dump of a private agent runtime. It intentionally excludes raw chats, personal data, tokens, cookies, private infrastructure paths, live credentials, and sensitive operational state.

## Why it matters

Modern agent workflows fail in three predictable ways: they lose continuity, mix facts with hypotheses, and overreach into actions that were never explicitly approved. REDNET Airin Skillbook addresses this by combining:

- **QMeta:** a classical branching engine for meta-skills, inspired by error correction, ensemble evaluation, threshold behavior, and traceable decision memory.
- **Airin/Hermes skills:** reusable `SKILL.md` modules for evaluation, safe process control, memory boundaries, public editing, visual generation, and defensive review.
- **Quiet Step doctrine:** read-only first, dry-run first, explicit permission gates, and no hidden side effects.
- **Public-safe release protocol:** sanitized summaries, synthetic examples, secret scanning, and manual review before publication.

## QMeta in one paragraph

QMeta is a classical engineering model for branching agent cognition. It does not claim physical quantum computation or nonlocal effects. It uses quantum-information language as an engineering analogy: branches are hypotheses, amplitudes are weights, interference strengthens convergent options, decoherence removes weak or unsafe branches, and measurement selects an answer or crystallizes a reusable skill.

## Safe use

Run installers in dry-run mode first:

```powershell
powershell -ExecutionPolicy Bypass -File packages\hermes\rednet-airin-meta-skills\install.ps1 -DryRun
```
